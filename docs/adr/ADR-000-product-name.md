# ADR-000: Product name is ConvertStation

**Status:** Accepted
**Date:** 2026-10-08

The engineering docs were written under the working title Universal Converter. The logo set in `logos/` is already ConvertStation, in light and dark, so the app, bundle id, and window title use that name.

`com.jewhurst.ConvertStation` is a development bundle id. Trademark, domain, and App Store name checks are still open. The older docs are left as the historical spec rather than rewritten in this pass.
